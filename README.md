# Mi Portafolio

Sitio web personal de una sola página con temática de editor de código (pestañas tipo VS Code, resaltado de sintaxis simulado y efecto de escritura).

## Estructura

```
mi-web/
├── index.html   → estructura de la página
├── style.css    → estilos y tema visual
├── script.js    → navegación entre pestañas y animación de texto
└── README.md    → este archivo
```

## Cómo verlo localmente

Abre `index.html` directamente en el navegador, o usa la extensión **Live Server** de VS Code para verlo con recarga automática.
